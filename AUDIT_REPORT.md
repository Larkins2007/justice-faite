# Отчёт проверки объединённой версии Justice Faite 3.1

## Источники
- `justice-faite-flat.zip`: исходный готовый HTML-сайт, CSS, JS и 7 баннеров.
- `justice-faite-site-3.0.zip`: исходники Eleventy, 9 Markdown-страниц, Nunjucks-шаблоны, CSS, JS и те же 7 баннеров.

## Принцип объединения
- Тексты страниц взяты из более полных Markdown-источников Site 3.0.
- Старые HTML-страницы использованы для проверки сохранности содержания и совместимости старых якорей.
- CSS и изображения сверены по SHA-256; они совпадают между архивами.
- Маршруты Site 3.0 переписаны с `/slug/` на `slug.html`, без папок.
- В исходниках были явные маркеры якорей `{#id}`; они преобразованы в настоящие HTML `id`, включая старые ссылки Flat.

## Проверки
- Список обязательных локальных файлов сверяется автоматически.
- Внутренние ссылки проверяются на существование HTML-целей и фрагментов.
- Проверяются дублирующиеся `id`, наличие стилей/скриптов, корректность HTML-парсинга и синтаксис JavaScript.
- Все 7 изображений проверены на совпадение SHA-256 между исходными архивами и выпуском.
- CSS в обоих архивах совпадает побайтно; выпуск использует тот же файл CSS.
- Все исходные HTML-якоря из Flat-версии сохранены; дополнительно созданы якоря для заголовков Site 3.0.
- Проверены 12 HTML-страниц: 0 отсутствующих локальных файлов, 0 сломанных внутренних ссылок, 0 отсутствующих фрагментов и 0 дублирующихся ID.
- Проверены 22 URL через локальный HTTP-сервер: все вернули HTTP 200 и непустое тело ответа.
- Синтаксис `main.js` проверен командой `node --check`; дополнительно пройдены 4 тестовых запроса поиска по кириллице и полному тексту страниц.
- Сверены все ID прежних HTML-страниц: ни один старый ID не потерян.

## Границы проверки
- Внешние Telegram-ссылки не выполнялись и не подтверждались запросами к Telegram.
- Реальная публикация в GitHub Pages/Cloudflare Pages/Render не выполнялась.
- В исходном разделе правил игр Site 3.0 нумерация мафии начинается с пункта 4.2; отсутствующий текст 4.1 не придумывался.
- Исходные метаданные включали `noindex, nofollow`; эта настройка сохранена, поэтому поисковые системы не должны индексировать страницы.
- Расписание игр создателей и центр обновлений в двух переданных архивах отсутствуют; эта сборка их не выдумывает.
