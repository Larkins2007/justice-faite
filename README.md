# Justice Faite 3.1 — Flat Release

Готовая статическая версия сайта. Все файлы для публикации находятся в корне архива: папки, сборка Node.js и npm не нужны.

## Загрузка с телефона в GitHub

1. Создай пустой репозиторий или открой существующий.
2. Распакуй `Justice_Faite_3.1_FLAT.zip` на устройстве.
3. Загрузи **содержимое** архива в корень репозитория (не сам ZIP и не вложенную папку).
4. Убедись, что в корне видны `index.html`, `style.css`, `main.js` и `banner_*.jpg`.
5. В настройках Pages выбери публикацию из корня ветки `main` (если используешь GitHub Pages).

## Файлы сайта

- `index.html` — главная и поиск.
- `*.html` — готовые страницы разделов.
- `style.css`, `main.js` — стили и интерактивность.
- `banner_*.jpg` — семь исходных изображений.
- `purge.html` — совместимый редирект на `norm.html`.
- `404.html` — страница ошибки.

## Совместимость ссылок

Сохранены адреса с `.html` из Flat-версии и старые фрагменты: например, `rules.html#p4-5`, `rest.html#what`, `norm.html#purge`, `join.html#who`. Внутренние ссылки из исходников Site 3.0 переписаны на плоские `.html`-адреса.

## Поиск и функции

Поиск находится на главной странице и ищет по названиям, ключевым словам и полным текстам всех девяти страниц. Переключатель темы, оглавление, якоря, ссылки на Telegram и переходы между страницами работают без серверной части.

## Исходники и сохранность

Полные исходные архивы обеих версий сохранены без изменений в отдельном файле `Justice_Faite_SOURCE_ARCHIVES.zip`. Он нужен только как резервная копия и не требуется для публикации. В плоский релиз не включены устаревшие файлы сборщика Eleventy, чтобы хостинг не пытался запускать ненужную сборку.

## Важное замечание

Архив проверен статически и через локальный HTTP-сервер. Публикация в аккаунте GitHub/Cloudflare/Render не выполнялась. После загрузки проверь выбранный способ хостинга и домен.
