# Justice Faite Site 3.0

Статическая библиотека страниц для Telegram-постов сообщества **Justice Faite**.

## Что сделано по ТЗ (MVP)

- Статический генератор **Eleventy** → чистый HTML
- Страницы-темы с блоком «Коротко», якорями, датой обновления
- Объединённые «Норма + Чистка» (`/norm/`), редирект `/purge/` → `/norm/`
- Новая страница **Как вступить** (`/join/`)
- Индивидуальные `<title>`, description, og:*, twitter:* (картинки — готовые баннеры)
- 404 со списком тем
- Мобильная вёрстка (360–430 px), кнопки ≥ 44 px
- Тёмная / светлая тема (system + ручной переключатель)
- Поиск с нормализацией ё/е
- Кнопки «В канал», «Вступить», «Все темы»
- `noindex` (только по ссылкам из канала)
- Markdown-файлы вместо JSON
- Бот: `@Justicefaitebot`

## Не сделано / позже

- Генерация OG-картинок 1200×630 (по ТЗ — не делаем сейчас)
- Аналитика (GoatCounter / Umami)
- Новости, расписание, калькулятор нормы
- Telegram Instant View
- Полный каталог магазина жетонов

## Локальный запуск

```bash
cd justice-faite-site
npm install
npm run dev
```

Открой http://localhost:8080

## Сборка

```bash
npm run build
```

Результат в `_site/`. Деплой на **Cloudflare Pages**, **GitHub Pages** или **Render Static Site** (бесплатно, без засыпания).

## Редактирование текстов

Файлы в `src/pages/*.md`. Frontmatter:

```yaml
---
layout: page.njk
slug: rest
title: Рест
short: "<p>Короткий ответ…</p>"
updated: 2026-11-27
order: 20
---
```

После commit → автодеплой (если настроен).
