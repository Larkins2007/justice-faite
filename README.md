# Justice Faite 3.2 — Winter Glass

Готовая статическая версия сайта. Node.js, npm и отдельная команда сборки не требуются.

## Что изменено

- Обновлена визуальная система сайта: тёмная изумрудная основа, матовое стекло, выраженные тонкие границы, мягкие блики и спокойный зимний фон.
- Главная получила новый приветственный экран и навигационную карусель.
- Все восемь прежних разделов главной доступны в карусели.
- Эмодзи-значки навигации и переключателя темы заменены согласованными SVG-пиктограммами.
- Существующий знак JF в шапке сохранён.
- Остальные страницы получили общий визуальный стиль, при этом прежние тексты, переходы и якоря сохранены.
- Все семь исходных JPG-баннеров сохранены побайтно.

## Установка

1. Сделай резервную копию текущего репозитория или текущей публикации.
2. Распакуй архив на устройстве.
3. Загрузи **содержимое** архива в корень репозитория, заменив одноимённые файлы.
4. Не удаляй другие существующие файлы репозитория, в частности Markdown-источники и служебные документы, которых нет в архиве.
5. После загрузки дождись автоматического обновления Cloudflare Worker, если Git-интеграция уже настроена.

Не создавай дополнительную вложенную папку `Justice_Faite_3.2_Winter_Glass` внутри корня сайта. В корне должны находиться `index.html`, `style.css`, `main.js` и остальные файлы сайта.

## Адаптация

- Телефон: около двух карточек и часть третьей.
- Планшет: около трёх карточек.
- Широкий экран: четыре карточки.
- Карусель поддерживает автопрокрутку, свайп, прокрутку и стрелки управления.
- При взаимодействии автоматическое движение временно ставится на паузу.
- При системной настройке уменьшения движения автопрокрутка отключается.
- Сохранён исходный переключатель темы: светлая, тёмная и системная.

## Проверки и ограничения

Архив содержит статические файлы. Встроенный отчёт `AUDIT_REPORT.md` описывает выполненные структурные проверки. `SHA256SUMS.txt` содержит контрольные суммы runtime-файлов.

Публичный Cloudflare Worker этим архивом не изменяется. Перед публикацией проверь отображение на реальном iPhone и других целевых экранах: автоматическая проверка исходников не заменяет визуальную проверку в браузере.
